# Melatonin und Kortisol

Interaktive Darstellung der Hormonverläufe auf Deutsch. Die Pfeile verschieben
Melatonin und Kortisol einzeln oder gemeinsam in 30-Minuten-Schritten.
Die Zeitachse bleibt bei 0–36 Stunden; die Achsen stehen mit etwas Abstand
außerhalb der Zeichenfläche. „Zurücksetzen“ stellt den Ausgangszustand wieder her.

`index.html` enthält alle benötigten Daten, Stile und Skripte. GitHub Pages
kann diesen Ordner unverändert als statische Website veröffentlichen.
Es werden nur aggregierte Gruppenwerte eingebettet.
